# 페이지 구성

## 서비스명
- Daker Hub

## 페이지 간 연결 관계
- `메인(/)`은 서비스의 대표 진입 페이지이며, `Hackathons`, `Camp`, `Ranking`, `MyPage`로 이동하는 출발점이다.
- `해커톤 목록(/hackathons)`에서 특정 해커톤을 선택하면 `해커톤 상세(/hackathons/[slug])`로 이동한다.
- `해커톤 상세(/hackathons/[slug])`에서는 `대회 신청`, 해커톤별 모집 보드, `Judge Preview 테스트`, `리더보드` 흐름으로 이어진다.
- `Judge Preview(/hackathons/[slug]/judge-preview)`는 해커톤 상세의 제출 섹션에서 진입하는 보조 분석 페이지다.
- `공유 팀 모집 보드(/camp)`는 메인과 해커톤 상세 양쪽에서 진입할 수 있으며, 전체 모집 보드와 해커톤별 모집 보드 흐름을 담당한다.
- `팀 보드(/camp/board/[teamId])`는 내가 만든 개인/팀 그룹의 설정, 문의, 합류 신청을 관리하는 Camp 내부 워크스페이스다.
- `전체 랭킹(/rankings)`과 `내 리더보드(/rankings/mine)`는 메인과 상단 내비게이션에서 진입하는 순위 확인 흐름이다.
- `내 페이지(/mypage)`는 찜한 해커톤, 내 그룹/팀 보드, 저장한 제출 개요를 모아보는 개인 관리 페이지다.

## 주요 페이지 설명

### 1. 메인 페이지 `/`
- 대표 해커톤 요약, 참가 보드 요약, 랭킹 요약을 한 번에 보여주며 서비스 전체 흐름을 빠르게 이해하게 한다.
- 상단 내비게이션과 카드 링크를 통해 `Hackathons`, `Camp`, `Ranking`, `MyPage`로 이동할 수 있다.

### 2. 해커톤 목록 페이지 `/hackathons`
- 공개 해커톤 목록을 보여주고 상태, 범위, 태그 기준으로 원하는 대회를 빠르게 찾을 수 있게 한다.
- 필터 버튼, 드롭다운, 태그 검색, `찜하기`, `상세 보기`, `팀 모집` 버튼으로 탐색과 이동 행동이 가능하다.

### 3. 해커톤 상세 페이지 `/hackathons/[slug]`
- 선택한 해커톤의 개요, 평가 기준, 일정, 상금, 팀/개인 참가, 제출, 리더보드를 한 페이지에서 확인하게 한다.
- `대회 신청`, `찜하기`, 해커톤별 모집 보드 이동, `Judge Preview 테스트`, 제출 저장, 팀 찾기/팀 만들기 같은 버튼으로 실제 참여 행동을 이어갈 수 있다.

### 4. Judge Preview 페이지 `/hackathons/[slug]/judge-preview`
- 저장된 제출 개요를 기준으로 예상 점수, 빠른 체크, 강점, 보완 포인트를 보여주는 제출 전 점검 페이지다.
- `제출 수정하기`, `상세로 돌아가기` 버튼으로 다시 제출 화면이나 해커톤 상세로 이동할 수 있다.

### 5. 공유 팀 모집 보드 `/camp`
- 여러 해커톤의 팀 모집글을 모아 보는 전체 보드이면서, 특정 해커톤으로 들어오면 그 해커톤만의 모집 보드로 동작한다.
- `전체`, `모집중 글`, `모집 마감 글`, `내 그룹` 필터와 `팀 만들기`, `문의 남기기`, 작성자 전용 `팀원 모집/보드 설정`, `팀 보드 열기` 버튼으로 조회·작성·관리할 수 있다.

### 6. 팀 보드 `/camp/board/[teamId]`
- 내가 만든 개인 그룹이나 팀 그룹 하나를 기준으로 모집 상태, 해커톤 연결, 연락 링크, 문의/합류 신청 inbox를 관리하는 화면이다.
- `팀원 모집` 또는 `보드 설정` 버튼으로 상태를 바꾸고, 해커톤 모집 보드나 상세 페이지로 다시 이동할 수 있다.

### 7. 전체 랭킹 페이지 `/rankings`
- 전체 해커톤 기준의 순위와 기간별 랭킹을 보여주며, 공개 제출 기준의 상대 위치를 빠르게 확인하게 한다.
- 기간 필터와 페이지 이동 링크를 통해 전체 순위를 비교하거나 `내 리더보드`로 넘어갈 수 있다.

### 8. 내 리더보드 페이지 `/rankings/mine`
- 내가 참여한 제출이나 리더보드 기준의 개인화된 순위 정보를 모아보는 페이지다.
- 상단 내비게이션과 링크를 통해 전체 랭킹이나 다른 주요 페이지로 다시 이동할 수 있다.

### 9. 내 페이지 `/mypage`
- 내 프로필, 찜한 해커톤, 내가 만든 그룹/팀 보드, 저장한 제출 개요를 한곳에 모아 개인 활동을 관리하게 한다.
- 찜 목록 확인, 팀 보드 이동, 저장한 제출 개요 확인 같은 행동이 가능하며 다른 상세 페이지로 다시 이동할 수 있다.

### 10. 운영 안내 페이지 `/about`
- 현재 서비스의 데이터 저장 방식, Supabase 연동 상태, 배포/운영 구조와 심사자 URL 확인 방식을 설명하는 참고 페이지다.
- 연동 상태 확인과 운영 가이드 열람이 가능하며, 필요 시 다른 주요 페이지로 다시 이동할 수 있다.
