# Final Shipping Checklist

## 실행 편의
- `npm start` 또는 `node server.js`로 바로 실행 가능
- 외부 접속 가능한 배포 URL 준비

## 제출 패키지
- 기획서, 웹, PDF 첫 문장 동일
- GitHub 저장소 링크 준비
- Vercel 배포 URL 준비
- PDF 변환본 준비

## 완성도
- 모바일 반응형 확인
- 로딩/데이터 없음/에러 상태 확인
- 필터/정렬 동작 확인
- 제출 폼과 Judge Preview 동작 확인

## 공개/심사
- localhost, 토큰, 비공개 정보 제거
- 심사자가 별도 키 없이 확인 가능한 상태
- `SUPABASE_SERVICE_ROLE_KEY` 같은 운영 비밀값이 GitHub/README/PDF에 없는 상태
- 수동 검증 방법 정리
