# 핵심 기능 명세

## 서비스명
- Daker Hub

## 핵심 기능 목록
- 해커톤 탐색 및 필터링
- 해커톤 상세 정보 확인
- 팀 모집글 작성 및 보드 조회
- 팀 모집글 문의 및 팀 보드 관리
- 개인 참가 신청
- 제출 개요 저장
- Judge Preview 예상 점수 점검
- 랭킹 및 내 활동 확인

## 1. 해커톤 탐색 및 필터링

### 기능 설명
- 사용자가 여러 공개 해커톤 중에서 현재 참여할 대상을 빠르게 찾을 수 있게 하는 탐색 기능이다.

### 입력 -> 동작 -> 결과
- 입력: 사용자가 해커톤 목록 페이지에서 상태 필터, 범위 선택, 태그 검색, 찜하기 버튼을 사용한다.
- 동작: 시스템이 선택한 조건에 맞는 해커톤만 다시 정렬해 목록으로 보여주고, 찜 상태는 사용자 기준으로 저장한다.
- 결과: 사용자는 현재 진행 중인 해커톤, 찜한 해커톤, 팀 모집과 연결된 해커톤을 빠르게 좁혀서 확인할 수 있다.

### 화면 설명용 문구
- “공개 해커톤 목록을 상태와 태그 기준으로 탐색하고, 관심 있는 대회를 바로 저장할 수 있습니다.”

### 페이지 항목 구성
- 상단 제목
- 상태 필터
- 범위 선택 드롭다운
- 태그 검색 입력
- 주요 태그 선택 영역
- 해커톤 카드 목록

## 2. 해커톤 상세 정보 확인

### 기능 설명
- 사용자가 특정 해커톤의 개요, 평가, 일정, 상금, 팀 정보, 제출 흐름을 한 화면에서 확인하는 기능이다.

### 입력 -> 동작 -> 결과
- 입력: 사용자가 목록에서 특정 해커톤 카드를 선택하거나 상세 보기 버튼을 누른다.
- 동작: 시스템이 해당 해커톤의 상세 정보와 연결된 모집글, 제출 상태, 리더보드를 함께 불러와 보여준다.
- 결과: 사용자는 대회 정보를 따로 흩어 찾아보지 않고, 참가 여부를 한 페이지 안에서 판단할 수 있다.

### 화면 설명용 문구
- “개요부터 일정, 평가, 참가, 제출, 리더보드까지 한 화면에서 이어서 확인할 수 있습니다.”

### 페이지 항목 구성
- 해커톤 제목 및 상태
- 일정/상금/팀 수 요약
- 개요 섹션
- 평가 기준 섹션
- 일정 섹션
- 팀/개인 참가 섹션
- 제출 섹션
- 리더보드 섹션

## 3. 팀 모집글 작성 및 보드 조회

### 기능 설명
- 사용자가 해커톤과 연결된 팀 모집글을 작성하거나, 이미 올라온 모집글을 찾아보는 기능이다.

### 입력 -> 동작 -> 결과
- 입력: 사용자가 `/camp`의 전체 모집 보드나 해커톤별 모집 보드에서 `팀 만들기` 버튼을 누르고 해커톤 선택, 팀명, 팀 소개, 모집 포지션, 외부 연락 링크를 입력한다.
- 동작: 시스템이 모집글을 저장하고, 연결된 해커톤이 있으면 해당 해커톤 문맥의 모집 보드에도 같은 글을 보이게 한다.
- 결과: 사용자는 특정 해커톤 기준 또는 전체 기준으로 팀 모집글을 올리고, 다른 사용자도 같은 보드에서 이를 확인할 수 있다.

### 화면 설명용 문구
- “전체 모집 보드와 해커톤별 모집 보드에서 팀 모집글을 작성하고, 다른 사용자의 모집글도 함께 탐색할 수 있습니다.”

### 페이지 항목 구성
- 전체/모집중/모집 마감/내 그룹 필터
- 팀 만들기 진입 버튼
- 해커톤 선택 입력
- 팀명 입력
- 팀 소개 입력
- 모집 포지션 입력
- 외부 연락 링크 입력
- 팀 모집 카드 목록

## 4. 팀 모집글 문의 및 팀 보드 관리

### 기능 설명
- 사용자는 마음에 드는 팀 모집글에 문의를 남길 수 있고, 작성자는 자신의 모집글만 수정하고 모집 상태를 변경할 수 있다.

### 입력 -> 동작 -> 결과
- 입력: 방문자는 모집글의 문의 입력창에 메시지를 작성하고, 작성자는 `팀 보드` 또는 `팀원 모집` 버튼으로 보드에 들어가 팀 정보나 모집 상태를 수정한다.
- 동작: 시스템은 문의를 작성자 전용 inbox로 저장하고, 팀 작성자에게만 보드 설정 폼과 문의 목록을 보여준다.
- 결과: 일반 사용자는 공개 보드에서 문의를 남길 수 있고, 작성자는 자신의 팀 보드에서 모집과 문의 흐름을 함께 관리할 수 있다.

### 화면 설명용 문구
- “관심 있는 팀에는 문의를 남기고, 내가 만든 그룹은 팀 보드에서 직접 관리할 수 있습니다.”

### 페이지 항목 구성
- 문의 입력창
- 문의 남기기 버튼
- 작성자 전용 팀 보드 버튼
- 보드 설정 폼
- 작성자 전용 문의 목록

## 5. 개인 참가 신청

### 기능 설명
- 팀을 찾기 전이라도 사용자가 특정 해커톤에 개인으로 바로 참가 의사를 남길 수 있게 하는 기능이다.

### 입력 -> 동작 -> 결과
- 입력: 사용자가 해커톤 상세에서 `대회 신청` 또는 `개인으로 바로 신청` 버튼을 누른다.
- 동작: 시스템이 해당 사용자의 개인 그룹 상태를 저장하고, 같은 해커톤에 중복 등록되지 않도록 처리한다.
- 결과: 사용자는 팀이 없어도 먼저 개인 그룹으로 시작할 수 있고, 이후 팀 보드에서 팀원 모집으로 전환할 수 있다.

### 화면 설명용 문구
- “팀이 없어도 먼저 개인 그룹으로 시작한 뒤, 필요하면 팀원 모집으로 전환할 수 있습니다.”

### 페이지 항목 구성
- 대회 신청 버튼
- 개인 참가 신청 버튼
- 신청 결과 메시지

## 6. 제출 개요 저장

### 기능 설명
- 참가자가 프로젝트 제출 전에 핵심 제출 정보를 구조화해 저장하는 기능이다.

### 입력 -> 동작 -> 결과
- 입력: 사용자가 프로젝트 제목, 팀·참가자, 서비스 개요, 페이지 구성, 시스템 구성, 핵심 기능 명세, 주요 사용 흐름, 개발 및 개선 계획을 입력한다.
- 동작: 시스템이 입력값을 사용자 기준 제출 개요로 저장하고, 같은 해커톤 상세와 내 페이지에서 다시 불러온다.
- 결과: 사용자는 제출 직전 내용을 정리된 형식으로 저장해 두고, 수정하거나 점검에 재활용할 수 있다.

### 화면 설명용 문구
- “제출 전에 필요한 핵심 정보를 정리된 형식으로 저장하고 다시 불러올 수 있습니다.”

### 페이지 항목 구성
- 프로젝트 제목 입력
- 팀·참가자 입력
- 서비스 개요 입력
- 페이지 구성 입력
- 시스템 구성 입력
- 핵심 기능 명세 입력
- 주요 사용 흐름 입력
- 개발 및 개선 계획 입력
- 제출 저장 버튼

## 7. Judge Preview 예상 점수 점검

### 기능 설명
- 저장한 제출 개요를 기준으로 예상 점수와 보완 포인트를 빠르게 확인하는 확장 기능이다.

### 입력 -> 동작 -> 결과
- 입력: 사용자가 해커톤 상세 제출 섹션에서 `Judge Preview 테스트` 버튼을 누른다.
- 동작: 시스템이 최근 저장한 제출 개요를 분석해 항목별 점수, 빠른 체크, 강점, 보완 포인트를 계산해 보여준다.
- 결과: 사용자는 실제 제출 전 부족한 항목을 미리 확인하고 제출 완성도를 높일 수 있다.

### 화면 설명용 문구
- “저장한 제출 내용을 기준으로 예상 점수와 보완 포인트를 빠르게 확인할 수 있습니다.”

### 페이지 항목 구성
- 예상 총점 카드
- 항목별 점수 카드
- 빠른 체크 목록
- 강점 영역
- 보완 포인트 영역
- 제출 수정하기 버튼
- 상세로 돌아가기 버튼

## 8. 랭킹 및 내 활동 확인

### 기능 설명
- 사용자가 전체 순위와 자신의 활동 상태를 함께 확인하는 기능이다.

### 입력 -> 동작 -> 결과
- 입력: 사용자가 랭킹 페이지에서 기간 필터를 선택하거나, 내 페이지에서 찜한 해커톤과 저장한 제출 개요를 확인한다.
- 동작: 시스템이 전체 해커톤 랭킹 또는 사용자 기준 활동 데이터를 불러와 요약 카드와 목록으로 보여준다.
- 결과: 사용자는 현재 위치와 내가 남긴 활동 기록을 함께 확인하며 다음 행동으로 다시 이동할 수 있다.

### 화면 설명용 문구
- “전체 순위와 내 활동 기록을 함께 확인하며 다음 행동으로 바로 이어갈 수 있습니다.”

### 페이지 항목 구성
- 전체 랭킹 표
- 기간 필터
- 내 리더보드 요약
- 찜한 해커톤 목록
- 내가 쓴 팀 모집글 목록
- 저장한 제출 개요 목록

- 팀 모집글을 작성하고 조회하는 기능

## 한줄 정리
- Daker Hub의 핵심 기능은 “탐색 -> 참가 결정 -> 팀 모집/개인 참가 -> 제출 정리 -> 사전 점검 -> 활동 확인” 흐름이 끊기지 않도록 설계된 점에 있다.
