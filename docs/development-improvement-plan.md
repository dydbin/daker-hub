# 개발 및 개선 계획

## 서비스명
- Daker Hub

## 방향 요약
- 기본 구현은 해커톤 탐색, 참가 결정, 팀 모집, 제출 저장, Judge Preview, 랭킹 확인 흐름을 완성하는 데 집중한다.
- 이후 개선은 “심사자가 바로 체감하는 기능 강화”, “사용자 경험 고도화”, “장기 운영 구조 확장” 순서로 진행한다.

## 우선순위별 개선 계획

### 1. 우선순위 높음: Judge Preview 고도화
- 목표: 현재의 예상 점수 테스트를 더 설득력 있는 제출 보조 기능으로 확장한다.
- 개선 아이디어:
  - 항목별 감점 근거를 더 구체적으로 보여주기
  - 제출 저장본 비교 기능 추가
  - 제출 전 체크리스트 자동 생성 기능 추가
- 예상 일정: 기본 구현 완료 후 1차 개선 단계
- 기대 효과: 심사 확장 기능으로서의 차별성이 커지고, 사용자가 제출 직전 보완 포인트를 더 빠르게 파악할 수 있다.

### 2. 우선순위 높음: 팀 모집 보드 UX 개선
- 목표: 팀 찾기와 모집글 관리 흐름을 더 직관적으로 만든다.
- 개선 아이디어:
  - 모집글 정렬 기준 추가
  - 해커톤별 모집글 묶음 보기 강화
  - 문의 도착 여부, 최근 수정 여부 같은 상태 표시 추가
- 예상 일정: 기본 구현 완료 후 1차 개선 단계
- 기대 효과: 사용자가 필요한 팀을 더 빨리 찾고, 작성자도 자신의 모집글을 더 효율적으로 관리할 수 있다.

### 3. 우선순위 높음: 상세 페이지 가독성 개선
- 목표: 해커톤 상세에서 일정, 제출, 참가 흐름을 더 빠르게 이해할 수 있도록 한다.
- 개선 아이디어:
  - 일정 카드의 중요 마감일 강조
  - 제출 섹션의 저장 상태 가시화
  - 리더보드와 참가 섹션의 시각적 구분 강화
- 예상 일정: 기본 구현 완료 후 1차 개선 단계
- 기대 효과: 상세 페이지의 이해 속도가 올라가고, 사용자의 행동 결정 시간이 줄어든다.

### 4. 우선순위 중간: 개인화 기능 확장
- 목표: 사용자의 활동 기록을 더 안정적으로 이어서 관리할 수 있게 한다.
- 개선 아이디어:
  - 찜한 해커톤과 제출 개요의 개인 맞춤 정리 강화
  - 내 페이지에서 진행 상태별 요약 제공
  - 선택적 계정 기반 동기화 기능 추가
- 예상 일정: 2차 개선 단계
- 기대 효과: 반복 방문 사용자에게 더 일관된 개인화 경험을 제공할 수 있다.

### 5. 우선순위 중간: 알림/리마인드 기능
- 목표: 마감일과 모집 상태 변화를 사용자가 놓치지 않게 한다.
- 개선 아이디어:
  - 마감 임박 해커톤 표시
  - 찜한 해커톤 일정 리마인드
  - 내 모집글 문의 도착 알림
- 예상 일정: 2차 개선 단계
- 기대 효과: 사용자의 재방문 동기와 서비스 실사용성이 높아진다.

### 6. 우선순위 중간: 검색 및 랭킹 고도화
- 목표: 더 많은 데이터가 쌓였을 때 탐색성과 비교 경험을 강화한다.
- 개선 아이디어:
  - 해커톤 검색 정확도 개선
  - 랭킹 필터 세분화
  - 해커톤별 리더보드 비교 보기 추가
- 예상 일정: 2차 개선 단계
- 기대 효과: 정보 탐색과 비교 효율이 높아져 플랫폼형 서비스로 확장하기 쉬워진다.

### 7. 우선순위 장기: 계정 기반 기능 확장
- 목표: 기기와 세션이 달라져도 사용자 활동을 안정적으로 이어갈 수 있게 한다.
- 개선 아이디어:
  - 현재 커스텀 로그인 흐름을 더 견고한 운영용 인증 체계로 고도화
  - 계정 단위 프로필/권한 관리 세분화
  - 내 활동 기록 동기화와 세션 안정성 강화
- 예상 일정: 장기 개선 단계
- 기대 효과: 실제 운영 서비스 전환 시 사용자 데이터의 지속성과 권한 관리 수준을 높일 수 있다.

### 8. 우선순위 장기: 운영 안정성 및 관리자 기능
- 목표: 서비스가 커졌을 때 운영과 관리가 가능하도록 기반을 마련한다.
- 개선 아이디어:
  - 운영용 데이터 점검 화면
  - 잘못된 모집글/문의 관리 기능
  - 로그/상태 모니터링 체계 강화
- 예상 일정: 장기 개선 단계
- 기대 효과: 공개 서비스로 전환할 때 안정성과 운영 대응 속도를 높일 수 있다.

## 단계별 일정 제안

### 1단계: 기본 구현 직후
- Judge Preview 고도화
- 팀 모집 보드 UX 개선
- 상세 페이지 가독성 개선

### 2단계: 기능 확장
- 개인화 기능 확장
- 알림/리마인드 기능
- 검색 및 랭킹 고도화

### 3단계: 운영 서비스 전환 준비
- 계정 기반 기능 확장
- 운영 안정성 및 관리자 기능

## 한줄 정리
- Daker Hub의 개선 계획은 먼저 핵심 시연 가치와 UX를 강화하고, 그 다음 개인화와 알림을 확장하며, 마지막으로 계정 기반 운영 구조까지 확장하는 순서로 진행한다.
