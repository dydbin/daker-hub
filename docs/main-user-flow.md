# 주요 사용 흐름

## 서비스명
- Daker Hub

## 대표 사용자 흐름

### 1. 메인 페이지 진입
- 사용자는 메인 페이지에서 대표 해커톤 요약, 참가 보드 요약, 랭킹 요약을 먼저 확인한다.
- 이 단계에서 사용자는 `Hackathons`, `Camp`, `Ranking`, `MyPage` 중 원하는 흐름으로 이동할 수 있다.

### 2. 해커톤 탐색
- 사용자는 해커톤 목록 페이지에서 상태 필터, 범위 선택, 태그 검색을 사용해 원하는 대회를 좁혀 본다.
- 관심 있는 해커톤은 `찜하기`로 저장하고, 더 자세히 보고 싶은 대회는 `상세 보기`로 이동한다.

### 3. 해커톤 상세 확인
- 사용자는 해커톤 상세 페이지에서 개요, 평가, 일정, 상금, 참가 방식, 리더보드를 한 번에 확인한다.
- 이 단계에서 사용자는 “이 대회에 참가할지”, “팀을 찾을지”, “개인으로 먼저 신청할지”를 결정한다.

### 4. 참가 방식 선택
- 사용자는 해커톤 상세에서 `대회 신청`을 눌러 개인으로 바로 신청하거나, 해커톤별 모집 보드로 이동해 팀 모집 흐름을 시작한다.
- 개인 참가를 선택하면 개인 그룹이 저장되고, 이후 같은 해커톤 안에서 팀원 모집으로 전환하거나 그대로 혼자 진행할 수 있다.

### 5. 팀 모집 또는 문의
- 사용자는 `/camp`의 전체 모집 보드 또는 해커톤별 모집 보드에서 모집중인 팀을 찾아 문의를 남기거나, 직접 팀 모집글을 작성한다.
- 그룹 작성자는 이후 `팀 보드`로 들어가 모집 상태와 내용을 조정하고, 도착한 문의와 합류 신청을 확인할 수 있다.

### 6. 제출 개요 작성
- 사용자는 해커톤 상세의 제출 섹션에서 프로젝트 제목, 서비스 개요, 페이지 구성, 시스템 구성, 핵심 기능 명세, 주요 사용 흐름 등을 입력한다.
- 저장 후에는 같은 상세 페이지와 내 페이지에서 제출 개요를 다시 확인하고 이어서 수정할 수 있다.

### 7. Judge Preview 점검
- 사용자는 제출 내용을 저장한 뒤 `Judge Preview 테스트`를 눌러 예상 점수와 부족한 항목을 확인한다.
- 점검 결과를 보고 다시 제출 내용을 수정하거나, 상세 페이지로 돌아가 다음 단계를 진행할 수 있다.

### 8. 랭킹 및 내 활동 확인
- 사용자는 `Ranking`에서 전체 순위를 확인하고, `MyPage`에서 찜한 해커톤, 내 그룹/팀 보드, 저장한 제출 개요를 다시 모아 본다.
- 이를 통해 현재 참여 상태를 정리하고, 다시 해커톤 탐색이나 제출 수정 흐름으로 이어갈 수 있다.

## 예외 상황 대응

### 1. 정보 없음
- 조건에 맞는 해커톤이나 모집글이 없으면 빈 상태 문구를 보여 주어 현재 결과가 없음을 알리고, 다른 필터를 보거나 첫 글을 작성하도록 안내한다.
- Judge Preview에 분석할 저장본이 없으면 “아직 분석할 저장본이 없습니다.” 화면을 보여 주고 제출 화면으로 돌아가게 한다.

### 2. 입력 오류
- 팀 모집글이나 제출 입력에서 필요한 값이 비어 있거나 저장에 실패하면 즉시 성공 상태로 넘어가지 않고, 같은 화면에서 다시 수정할 수 있도록 유지한다.
- 개인 참가나 모집글 수정처럼 중복 또는 권한 문제가 있는 경우에는 결과 메시지로 실패 사유를 보여 준다.

### 3. 접속 불가 또는 저장소 연결 문제
- Supabase가 연결되지 않았거나 운영 준비가 덜 된 경우에는 `/about` 페이지에서 현재 저장 상태와 빠진 환경 변수 정보를 확인할 수 있다.
- 연동이 없는 환경에서는 메모리 기반 fallback으로 시연 화면을 유지해, 최소한의 탐색과 흐름 확인은 가능하도록 구성한다.

## 한줄 정리
- Daker Hub의 주요 사용 흐름은 “탐색 -> 상세 확인 -> 참가 결정 -> 해커톤별 모집 보드/개인 참가 -> 팀 보드 관리 -> 제출 저장 -> Judge Preview 점검 -> 랭킹/내 활동 확인” 순서로 이어진다.
